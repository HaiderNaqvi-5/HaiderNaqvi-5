### ⚡ Working principles

- Build AI features that are grounded in evidence and easy to review.
- Put critical business and security rules in services and databases, not just the interface.
- Treat startup cost, deployment weight, and input validation as part of the product.
- Prefer systems that stay understandable as they grow.
